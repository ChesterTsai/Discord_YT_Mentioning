# Prerequisites
運行`pip3 install -r requirements.txt`來下載所需的程序依賴<br>
run `pip3 install -r requirements.txt` to install required dependencies<br>
<br>
### .env
將".env.example"改名為".env"，並輸入對應的TOKEN/API以正常運行機器人<br>
rename ".env.example" to ".env", and insert the corresponding TOKEN/API to make the bot run correctly
